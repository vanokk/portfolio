## Overview

An internal web platform for project management, task tracking, and team collaboration, built around Agile and Scrum methodologies.

The application combines interactive Kanban boards, task management, sprint planning, and development progress tracking. With WebSocket integration, the platform supports real-time task updates and collaboration between multiple users.

The system allows teams to manage workflows, assign tasks, track their statuses, and coordinate project delivery in one place.

## Approach

- **Frontend Development.** Developed task and project management interfaces using React and TypeScript, building reusable components for the application's core workflows.
- **State Management.** Used Redux and Redux-Saga to manage application state, handle asynchronous operations, and communicate with backend APIs.
- **Interactive Boards.** Developed Kanban boards and interfaces for creating, editing, and tracking tasks organized by their current status.
- **Real-Time Updates.** Implemented task updates using WebSockets, enabling data synchronization and collaboration between users without requiring page reloads.
- **UI Styling.** Used TailwindCSS to build responsive components and maintain consistent styling across the application.
- **Backend Development.** Developed APIs and a WebSocket layer using NestJS to handle task operations and deliver updates to connected clients.
- **Team Collaboration.** Worked with other developers on API design, frontend and backend integration, and implementation of user workflows.

## Results

Developed core components of the project and task management interface, including **interactive Kanban boards and task management workflows**.

Implemented **real-time synchronization through WebSockets**, allowing team members to see task updates **without refreshing the page**.

Using React, TypeScript, Redux-Saga, and TailwindCSS, built **reusable frontend components** and organized **application state management and asynchronous operations**.

Developed **APIs and WebSocket handlers using NestJS** to connect the frontend with backend services and exchange updates between connected users.
