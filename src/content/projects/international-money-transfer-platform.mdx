## Overview

An international FinTech platform for cross-border money transfers, serving over 100,000 users across the United Kingdom, Europe, and the United States.

The platform combines user registration and identity verification (KYC), recipient management, international money transfers, digital wallets, payment processing, and transaction tracking.

It supports multiple payment and payout methods, including bank transfers, cash pickup, mobile money, and wallet-to-wallet transfers. The platform integrates with external payment providers and financial services to process international transactions.

## Approach

- **Frontend Development.** Developed and maintained web applications using Vue.js and Nuxt.js, including user registration, identity verification, money transfers, recipient management, digital wallets, and transaction history.
- **Architecture and Modernization.** Contributed to frontend architecture improvements and the migration from Vue 2 to Vue 3. Built reusable components and improved application performance and code maintainability.
- **Payment Provider Integrations.** Implemented and maintained integrations with Checkout.com, Worldpay, and Plaid. Worked on payment forms, saved cards, identity verification, and handling external API responses. Collaborated directly with providers' technical support teams to resolve integration issues.
- **Web Application Redesign.** Developed redesigned user flows for onboarding, money transfers, wallet transfers, transaction review, and transaction details. Used Figma MCP to speed up UI implementation and Chrome DevTools MCP for testing and debugging.
- **Backend Development.** Contributed to PHP/Symfony and Java services, including business logic, API integrations, and fixes involving multiple services.
- **Internal Administration Tools.** Developed and improved internal interfaces for managing financial operations, including payment approvals and rejections, status management, filtering, and error handling.
- **Performance and SEO Optimization.** Improved landing page performance and technical SEO by optimizing frontend code, resource loading, and page structure, with a focus on faster loading times and better PageSpeed scores.
- **Production Support.** Participated in rotating production support shifts, investigating payment failures, transaction processing issues, and urgent customer incidents. Used Elasticsearch MCP and AI tools to analyze logs and identify root causes.
- **Testing and Code Quality.** Developed unit tests using Vitest, maintaining approximately 90% test coverage for the features I delivered. Participated in code reviews and maintained code quality.
- **AI-Assisted Development.** Used Codex and MCP integrations with Figma, Chrome DevTools, Elasticsearch, GitLab, and Atlassian to improve development, testing, debugging, and technical documentation workflows.
- **Cross-Team Collaboration.** Worked closely with product managers, frontend and backend developers, QA engineers, mobile developers, and external payment providers. Participated in requirements analysis, task breakdown, and technical documentation in Confluence.

## Results

The platform's **core money transfer flows were modernized**, **payment integrations were expanded**, and **internal tools for managing financial operations were improved**.

The **Vue 2 to Vue 3 migration**, reusable frontend components, and automated testing helped improve **application maintainability and the reliability of new releases**. I maintained **approximately 90% unit test coverage** for the features I delivered.

**Performance and SEO optimization:** Improved landing page loading performance and technical SEO by optimizing frontend code and resource loading, achieving **90+ scores in Google PageSpeed Insights**.

Using **Figma MCP and Chrome DevTools MCP** significantly accelerated UI development and validation, reducing the time required for certain implementation tasks **from hours to minutes**.

AI-assisted workflows with **Elasticsearch MCP** reduced root cause investigation time for production incidents **from 2–3 hours to approximately 10 minutes**.

Regular participation in production support helped identify and **resolve urgent customer issues, payment failures, and transaction processing problems quickly**.
