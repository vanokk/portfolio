## Overview

A career development and talent management platform connecting individuals, employers, and education providers.

The platform helps individuals explore career opportunities, understand employer skill requirements, and plan their professional development. Employers can identify suitable candidates, while education providers gain insights into labor market needs.

The product includes skills-based job matching, detailed user profiles, career planning tools, analytical dashboards, and information-rich landing pages.

Built from the ground up by a large development team, the platform includes a wide range of interconnected pages, reusable UI components, and data-driven interfaces.

## Approach

- **Frontend Development.** Contributed to building the platform from scratch using Vue 2 and Vuex. Developed numerous application pages, user interfaces, and reusable components for different user roles and workflows.
- **Component Architecture.** Developed and maintained reusable Vue components and a Storybook component library to ensure UI consistency and simplify development across a large application.
- **Analytics and Data Visualization.** Built analytical dashboards and interactive charts using Highcharts, presenting complex data in a clear and accessible format.
- **Backend Integration.** Integrated frontend functionality with Laravel REST APIs, handling data exchange, application state, and dynamic content.
- **Performance Optimization.** Optimized data-heavy landing pages by improving frontend code, resource loading, and rendering performance, achieving **90+ scores in Google PageSpeed Insights**.
- **SEO Optimization.** Improved technical SEO of landing pages, focusing on page structure, semantic HTML, metadata, and search engine accessibility.
- **UI Architecture and Styling.** Used BEM methodology and reusable component patterns to keep the frontend codebase structured, consistent, and maintainable.
- **Team Collaboration.** Worked as part of a large development team, collaborating with other engineers on complex features, shared components, code reviews, and integration tasks.

## Results

Contributed to building a **large career development platform from the ground up**, delivering numerous application pages, reusable frontend components, and interfaces for different user groups.

Developed and maintained a **Storybook component library** that **improved UI consistency** and simplified the development of new features across the platform.

Built **analytical dashboards and interactive Highcharts visualizations**, making complex platform data easier to understand and explore.

Optimized data-heavy landing pages and improved technical SEO, achieving **90+ scores in Google PageSpeed Insights**.

Helped maintain a **scalable and consistent frontend architecture** through reusable Vue components, structured BEM styling, and close collaboration within a large development team.
