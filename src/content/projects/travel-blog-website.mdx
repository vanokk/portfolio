## Overview

A responsive personal travel blog focused on travel stories, destinations, and photography.

The project involved converting Figma designs into pixel-perfect web pages, with a strong focus on visual accuracy, responsive layouts, clean code, and accessibility.

## Approach

- **Pixel-Perfect Implementation.** Converted Figma designs into HTML and CSS layouts, carefully matching typography, spacing, colors, and visual details.
- **Responsive Design.** Built responsive pages that adapted to different screen sizes, including desktop, tablet, and mobile devices.
- **BEM Methodology.** Followed the Block Element Modifier (BEM) methodology to maintain a consistent, structured, and reusable CSS architecture.
- **Accessibility.** Applied semantic HTML, appropriate heading structures, descriptive image alt text, and keyboard-friendly navigation to improve accessibility and usability.

## Results

Delivered **responsive, pixel-accurate web pages** closely matching the original Figma designs.

Maintained a **clean and scalable CSS structure using BEM methodology**, making styles easier to understand and maintain.

Improved accessibility through **semantic HTML, keyboard-friendly navigation, and accessible content structure**, making the website easier to use across different devices and interaction methods.
