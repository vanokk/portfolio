## Overview

A web application for paying utility bills in Germany, built from scratch using React and Redux.

The platform allows users to authenticate, upload utility bills, view billing information extracted by backend services, and explore their expenses through interactive charts.

## Approach

- **Frontend Development.** Developed core user interfaces and reusable components using React, Redux, and Bootstrap.
- **Authentication.** Implemented login and registration interfaces with backend API integration.
- **Document Upload.** Built interfaces for uploading utility bills and displaying data processed by backend services.
- **Data Visualization.** Created interactive charts using Chart.js to display utility expenses and billing information.
- **Responsive Design.** Developed mobile-friendly layouts and payment forms using Bootstrap.

## Results

Contributed to the **initial development of the platform**, delivering core frontend functionality for **authentication, document uploads, billing data visualization, and payment interfaces**.

Built **reusable React components** and **responsive layouts for desktop and mobile devices**.
